# Arsitektur Dual-Mode (Server/Client LAN) dalam Satu Binary Tauri

Aplikasi dikemas sebagai satu installer `.exe` Tauri yang dapat dikonfigurasi saat dijalankan sebagai **Server Terminal** atau **Client Terminal**. Pada **Server Terminal**, proses Rust Tauri menjalankan database SQLite (mode WAL) dan membuka HTTP API lokal di jaringan LAN toko (menggunakan Axum), sementara 3–5 **Client Terminal** berkomunikasi ke IP **Server Terminal** melalui HTTP untuk seluruh operasi baca/tulis data, sedangkan pencetakan **Receipt** dan pemicu laci uang tetap dieksekusi secara lokal di masing-masing terminal. Pendekatan ini dipilih dibanding sinkronisasi database multi-master (*offline-first*) atau instalasi database server terpisah (seperti PostgreSQL) agar instalasi di toko ritel Windows tetap satu klik tanpa risiko bentrok stok (*race condition*) saat beberapa **Cashier** menjual barang terakhir secara bersamaan.
